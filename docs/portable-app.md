# 视频制作工作台 · Windows 免安装版

## 解压后打开主程序

把整个压缩包解压到一个普通文件夹，双击 `VideoWorkbench.exe`。不要在压缩包里直接运行，也不要只复制一个 EXE：`_internal` 和 `VideoWorkbenchWorker.exe` 是运行与视频组件，须放在一起。

新电脑无需另装 Python、Qt 或 FFmpeg。声音在「设置 → 配音设置」或「成片 → 配音设置」选择，保存后供后续生成使用，已有视频不变。Edge 需要联网，Google Cloud 需要本机官方授权并逐次确认可能计费的请求；Windows 离线声音需要系统中文语音，可通过「管理 Windows 语音」安装。

首次使用「设置 → Gemini 连接助手」查找本机 Chrome，并在 App 专用窗口登录。需要自动推荐／文稿时，还需安装、配置并官方登录 Antigravity CLI；可选 GPT 润色需 Codex CLI。安装包不含这些服务的账号或凭据。检测不到时，在「设置」选择本机程序路径。

## 作品独立保存在本机

默认数据目录是 `%LOCALAPPDATA%\VideoMaker`，不写到 App 安装文件夹。重新解压或替换 App 不会替换作品。打开「我的作品」可继续原有内容；先保存并关闭旧窗口，再打开新版。

新电脑会创建自己的数据和专用浏览器目录，并自动选择可用端口。不要从开发电脑复制 Cookie、密码或 CLI 登录文件。备份作品前退出 App，再备份整个数据目录；导出文稿和成片不等于完整数据备份。当前尚无跨机器项目导入界面。

## 从选题到视频

每日推荐 → 选择选题 → 确认文稿 → 确认分镜 → 成片 → 生成视频。

使用技术示意动画、所选中文旁白和同步字幕。旧设置仍沿用 Windows 声音；可在视频设置切换旧工程的 Google WaveNet-B 或 Edge 云健／云希，历史试听不发起在线生成。可在「素材」给镜头导入图片或视频，点击「用于此镜头」后再生成。导入画面等比显示、原声静音，短片延长末帧，长片截取前段。导入配音目前仅可预览，不参与成片。

完成后在 App 内预览，或打开成片目录取得 MP4 和 SRT。无需手工建立日期目录。

## 无法打开或生成失败

- 找不到视频组件：重新完整解压，保留主程序、工作进程和 `_internal`。
- 提示工作台已打开：同一数据目录只能打开一个窗口，回到原窗口继续。
- 缺少 Chrome 或 CLI：在「设置」重新检测／选择本机程序，并完成官方登录。
- 缺少中文语音：通过 Windows 语言和语音设置安装，再重试。
- 旧成片不匹配新文稿／分镜／素材：重新生成；旧成片仍保留。
